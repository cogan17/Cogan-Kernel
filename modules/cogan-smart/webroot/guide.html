📖 Panduan

⚡Daya🌡️Suhu🛠️Manager🧩Modul📱Aplikasi

Cogan Smart Kernel menjaga HP tetap adem dan mencatat suhunya. Panduan ini menjelaskan tiap tab dan tombol dengan bahasa sederhana.

Cogan Smart Kernel keeps the phone cool and records its temperature. This guide explains every tab and button in plain words.

🚀 Mulai cepat

🚀 Quick start

  1. Pilih mode di tab Daya: 🌿 Hemat, 🧠 Kernel Default atau 🎮 Performa.
  2. Lihat Ringkasan di Manager: pengendali dan pencatat harus aktif / mencatat.
  3. HP terasa panas? Buka tab Suhu: penyebabnya tercatat di sana.
  1. Choose a mode in the Power tab: 🌿 Power saver, 🧠 Kernel Default or 🎮 Performance.
  2. Check the Summary in Manager: the controller and recorder should be active / recording.
  3. Phone feels hot? Open the Temperature tab: the cause is recorded there.

🛠️ Manager: pusat kendali

🛠️ Manager: the control centre

  • Ringkasan: suhu Badan HP, baterai, prosesor, status pengendali dan pencatat, grafik suhu 1 jam, penyebab panas, dan hasil pindai modul terakhir (pindai di tab Modul).
  • 📱 Aplikasi: jumlah aplikasi berbahaya dan status blokir APK dari tab Aplikasi.
  • Mode daya: menampilkan mode yang dipilih di tab Daya. Manager hanya memantau; ganti mode di tab Daya.
  • Prosesor: cara CPU mengatur kecepatannya (governor). Kernel Default cocok untuk harian.
  • RAM: kompresi ZRAM. LZ4 lebih cepat, ZSTD lebih hemat RAM. Centang Terapkan CPU/RAM saat boot, tekan Simpan, lalu restart HP.
  • Kontrol Daya dan Kontrol Suhu: semua tombol untuk menerapkan setelan dari tab Daya dan Suhu.
  • Summary: phone body, battery and processor temperature, controller and recorder status, a 1-hour temperature chart, the heat cause and the last module scan (scan in the Modules tab).
  • 📱 Apps: how many apps are dangerous and the APK block status, from the Apps tab.
  • Power mode: shows the mode chosen in the Power tab. Manager only watches it; change the mode in the Power tab.
  • Processor: how the CPU sets its speed (governor). Kernel Default suits everyday use.
  • RAM: ZRAM compression. LZ4 is faster, ZSTD saves more RAM. Tick Apply CPU/RAM at boot, tap Save, then restart the phone.
  • Power controls and Temperature controls: every button that applies the settings of the Power and Temperature tabs.

🔘 Arti tombol

🔘 What the buttons do

  • 💾 Simpan: menyimpan setelan. Berlaku pada pemeriksaan berikutnya.
  • ⚡ Paksa / Terapkan dan Terapkan sekarang: menyimpan, menyalakan, lalu langsung berlaku.
  • ↺ Reset default / Ikuti kernel: kembali ke setelan bawaan. Riwayat suhu tidak dihapus.
  • ⏹ Hentikan / ▶ Mulai: mematikan atau menyalakan pengendali atau pencatat.
  • 🗑 Hapus riwayat: menghapus catatan suhu. Log yang sudah disimpan di Download tetap ada.
  • 💾 Save: stores the settings. They take effect at the next check.
  • ⚡ Force / Apply and Apply now: saves, starts and applies at once.
  • ↺ Reset defaults / Follow kernel: back to the default settings. Temperature history is kept.
  • ⏹ Stop / ▶ Start: turns the controller or recorder off or on.
  • 🗑 Clear history: deletes the temperature records. Logs already saved in Download stay.

⚡ Daya

⚡ Power

  • 🌿 Hemat: CPU besar dibatasi 60%, Badan HP dijaga ≤ 39 °C.
  • 🧠 Kernel Default: Badan HP dijaga ≤ 41 °C. Pilihan harian.
  • 🎮 Performa: tenaga penuh, baru direm saat Badan HP 44 °C.
  • 🔌 Cas: berhenti mengecas di 95% dan lanjut di 90% (bisa diubah). Cari saklar cas cukup sekali, saat charger tercolok.
  • ⚙️ Setelan mode: ubah angka suhu tiap mode. Simpan dari Manager.
  • 📝 Aktivitas: catatan apa saja yang dilakukan modul.
  • 🌿 Power saver: big CPU capped at 60%, phone body kept ≤ 39 °C.
  • 🧠 Kernel Default: phone body kept ≤ 41 °C. The everyday choice.
  • 🎮 Performance: full power, held back only at a 44 °C phone body.
  • 🔌 Charging: stops at 95% and resumes at 90% (adjustable). Detect charging switch once, with the charger plugged in.
  • ⚙️ Mode settings: change each mode's temperature. Save from Manager.
  • 📝 Activity: a record of what the module did.

🌡️ Suhu

🌡️ Temperature

  • Sekarang: suhu Badan HP dan bagian HP lain saat ini.
  • 📊 Ringkasan: grafik, berapa lama HP panas, penyebab panas, dan suhu per aplikasi dan per mode.
  • 💾 Simpan log: menyimpan ringkasan (.txt) dan semua data (.csv) ke folder Download/CoganThermal.
  • ⚙️ Setelan: kapan HP dianggap panas (bawaan 41 °C), lama riwayat (7 hari) dan notifikasi (bawaan mati).
  • Now: the phone body and other parts right now.
  • 📊 Summary: chart, how long the phone was hot, the heat causes, and temperature per app and per mode.
  • 💾 Save logs: saves the summary (.txt) and all data (.csv) to the Download/CoganThermal folder.
  • ⚙️ Settings: when the phone counts as hot (default 41 °C), how long history is kept (7 days) and notifications (off by default).

🧩 Modul

🧩 Modules

  • Memeriksa modul root lain: ✅ aman, ⚠️ perlu dicek, ⛔ berbahaya. Ini dugaan; baca Bukti sebelum bertindak.
  • 🛡️ Percaya: modul tidak ditandai lagi dan terlindung dari hapus tidak sengaja.
  • ⏸ Nonaktifkan / ▶ Aktifkan: berlaku setelah reboot.
  • 🗑 Hapus sampai akar: menghapus modul beserta skrip boot dan prosesnya. Bisa dibatalkan sebelum reboot.
  • 📜 Skrip boot di luar modul: skrip yang jalan saat boot tapi tidak terlihat di daftar modul.
  • Checks other root modules: ✅ safe, ⚠️ needs a look, ⛔ dangerous. These are guesses; read the Evidence before acting.
  • 🛡️ Trust: the module is no longer flagged and is protected from accidental removal.
  • ⏸ Disable / ▶ Enable: takes effect after a reboot.
  • 🗑 Remove completely: removes the module with its boot scripts and processes. Can be undone before rebooting.
  • 📜 Boot scripts outside modules: scripts that run at boot but are not in the module list.

📱 Aplikasi

📱 Apps

  • Memeriksa semua aplikasi yang kamu pasang: ✅ aman, ⚠️ perlu dicek, ⛔ berbahaya. Tandanya dari sumber pasang dan izin aplikasi, bukan antivirus.
  • Sumber: dari toko aplikasi, file APK kiriman chat atau sosmed, atau file APK dari browser dan file manager. APK kiriman WhatsApp atau sosmed paling sering dipakai penipuan.
  • Izin berbahaya: baca SMS (kode OTP), aksesibilitas (bisa membaca dan menekan layar), admin perangkat (sulit dihapus), baca notifikasi, tampil di atas aplikasi lain, ikon disembunyikan.
  • 👁️ Gerak-gerik: kapan terakhir aplikasi memakai kamera, mikrofon, lokasi, SMS, kontak, telepon atau clipboard, pemakaian internet 7 hari dan baterai sejak cas penuh.
  • ⚠️ Perlu dicek / Semua / 💤 Jarang dipakai: pilih daftar yang ditampilkan. Jarang dipakai artinya tidak dibuka 7 hari atau lebih.
  • 🛡️ Percaya: aplikasi tidak ditandai lagi dan tidak bisa terhapus tanpa sengaja.
  • 🗑 Hapus sampai akar: melepas admin perangkat, menghentikan dan menghapus aplikasi dari semua pengguna (termasuk Aplikasi Ganda dan Ruang Kedua), lalu menghapus sisa data dan file APK yang sama di penyimpanan. Tidak bisa dibatalkan. Aplikasi sistem dan root manager tidak bisa dihapus dari sini.
  • 🛡️ Blokir APK dari chat & sosmed: bawaan aktif. Aplikasi chat, sosmed, email dan SMS (WhatsApp, Telegram, Signal, Instagram, Facebook, Threads, TikTok, X, Gmail, Outlook, Pesan dan lainnya) tidak bisa memasang aplikasi. Bila izinnya dinyalakan lagi di Pengaturan, modul mencabutnya dalam beberapa detik dan memberi notifikasi. Browser dan file manager tetap bisa.
  • Checks every app you installed: ✅ safe, ⚠️ needs a look, ⛔ dangerous. The marks come from where the app came from and what it may do; this is not an antivirus.
  • Source: an app store, an APK file sent through chat or social apps, or an APK file from a browser or file manager. APKs sent through WhatsApp or social apps are the most common scam.
  • Dangerous rights: reads SMS (OTP codes), accessibility (can read and tap the screen), device admin (hard to remove), reads notifications, draws over other apps, hidden icon.
  • 👁️ Activity: when the app last used the camera, microphone, location, SMS, contacts, phone or clipboard, its internet use in 7 days and battery since the last full charge.
  • ⚠️ Needs a look / All / 💤 Rarely used: choose which list to show. Rarely used means not opened for 7 days or more.
  • 🛡️ Trust: the app is no longer flagged and cannot be removed by accident.
  • 🗑 Remove completely: releases its device admin, stops and removes the app for every user (Dual apps and Second space too), then deletes leftover data and identical APK files in storage. This cannot be undone. System apps and the root manager cannot be removed here.
  • 🛡️ Block APKs from chat & social apps: on by default. Chat, social, email and SMS apps (WhatsApp, Telegram, Signal, Instagram, Facebook, Threads, TikTok, X, Gmail, Outlook, Messages and more) cannot install apps. If the right is turned on again in Settings, the module takes it back within seconds and shows a notification. Browsers and file managers still can.

🛠️ Mode Dev

🛠️ Dev mode

  • Bawaan mati: tampilan ringkas untuk pemakaian sehari-hari.
  • Nyala: muncul detail teknis, misalnya node kernel, hasil baca ulang, hook boot ZRAM, semua sensor, dan data mentah modul.
  • Off by default: a short view for everyday use.
  • On: shows technical detail such as kernel nodes, readback, ZRAM boot hooks, every sensor and raw module data.

❓ Tanya jawab

❓ FAQ

  • Tidak bisa memasang APK dari WhatsApp atau Telegram? Itu blokir APK dari tab Aplikasi. Bila kamu yakin APK-nya aman, matikan blokir dulu atau buka file-nya dari file manager.
  • Terlanjur memasang APK penipuan? Tekan Hapus sampai akar di tab Aplikasi, lalu ganti kata sandi dan PIN bank, dan hubungi bank bila ada transaksi aneh. Menghapus aplikasi tidak membatalkan data yang sudah dicuri.
  • Prosesor 50–60 °C saat santai, wajar? Ya. Panas dihitung dari suhu Badan HP, yang terasa di tangan.
  • Kolom GPU di log kosong? GPU sedang tidur (layar mati atau tidak dipakai), jadi sensornya tidak terbaca. Normal.
  • Arus cas sampai 10–16 A? Itu HyperCharge 120 W saat mengecas cepat. Normal.
  • ZRAM tetap LZ4 setelah restart? Centang Terapkan CPU/RAM saat boot, tekan Simpan, lalu restart. Butuh modul v2.10.8 atau lebih baru.
  • HP gagal masuk sistem? Safe mode KernelSU mematikan semua modul sementara. Nyalakan lagi di root manager → Modul, lalu reboot.
  • Cannot install an APK from WhatsApp or Telegram? That is the APK block in the Apps tab. If you are sure the APK is safe, turn the block off first or open the file from a file manager.
  • Already installed a scam APK? Tap Remove completely in the Apps tab, then change your passwords and bank PIN, and call your bank if you see strange transactions. Removing the app does not undo data that was already stolen.
  • Processor at 50–60 °C while idle, normal? Yes. Heat is measured from the phone body, which is what you feel.
  • GPU column empty in the log? The GPU is asleep (screen off or unused), so its sensor cannot be read. Normal.
  • Charging current up to 10–16 A? That is 120 W HyperCharge fast charging. Normal.
  • ZRAM still LZ4 after a restart? Tick Apply CPU/RAM at boot, tap Save, then restart. Needs module v2.10.8 or newer.
  • Phone fails to boot? KernelSU safe mode turns every module off for a while. Turn them back on in the root manager → Modules, then reboot.
