English

Fixes:
- The ZRAM init hook is now actually run by Android init. In v2.10.4–v2.10.5 the initrc exec line followed shell rules instead of init rules: the quotes were cut and $ was rejected, so the ZSTD choice was never applied at boot (owner's phone test on 28 Oct: zram0 stayed lz4, no hook marker).
- The hook program is now one init token using the escapes init supports; every $ is written as $$$$ because init expands exec arguments twice. The program and its checks are unchanged.
- The v2.10.5 MediaTek DRAM detection remains and is confirmed on the phone.

Limits:
- No live ZRAM reset, swap disabling, ZRAM resize, kernel, KMI or partition changes. No new kernel flash is needed.
- The hook runs at the init, early-fs and post-fs stages. If ZRAM does not exist yet or is already active at those stages, the marker reports missing or pending instead of matching. v2.10.6 has not been phone-tested.

How to test:
1. Install as a module update through the root manager, then reboot.
2. Open Manager. With ZSTD saved and Apply at boot enabled, the RAM section should show zram0: zstd and the line "Hook boot ini: zstd post-fs matching".
3. Or in a root terminal: cat /sys/block/zram0/comp_algorithm; cat /dev/.cogan_smart_zram_init
