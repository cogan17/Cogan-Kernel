Cogan Smart Kernel v2.10.8 / versionCode 27 — paket uji / test build

Indonesia

Perbaikan:
- Pilihan kompresi ZRAM (LZ4/ZSTD) kini ditulis tepat sebelum ZRAM dinyalakan. Di HyperOS rothko, ZRAM dinyalakan oleh alat Xiaomi system_perf_init sekitar detik ke-9,7 boot, bukan saat boot selesai seperti dugaan v2.10.7.
- Hook kini berjalan pada tahap load-bpf-programs: sesudah skrip vendor MediaTek menulis lz4 (post-fs-data) dan sebelum Xiaomi menjalankan system_perf_init. Tahap boot-completed dari v2.10.7 dihapus.

Batas yang tetap berlaku:
- ZRAM aktif tidak direset, swap tidak dimatikan, ukuran ZRAM, kernel, KMI dan partisi tidak diubah. Tidak perlu flash kernel baru.
- v2.10.8 belum diuji di HP.

Cara uji:
1. Pasang sebagai pembaruan modul melalui root manager, lalu reboot.
2. Buka Manager. Dengan ZSTD tersimpan dan Terapkan saat boot aktif, bagian RAM seharusnya menampilkan zram0: zstd dan "Hook boot ini: zstd load-bpf-programs matching".
3. Atau di terminal root: cat /sys/block/zram0/comp_algorithm; cat /dev/.cogan_smart_zram_init

English

Fixes:
- The ZRAM compression choice (LZ4/ZSTD) is now written just before ZRAM starts. On rothko HyperOS, ZRAM is started by Xiaomi's system_perf_init about 9.7 seconds into boot, not when boot completes as v2.10.7 assumed.
- The hook now runs on load-bpf-programs: after the MediaTek vendor script writes lz4 (post-fs-data) and before Xiaomi starts system_perf_init. The v2.10.7 boot-completed run is removed.

Limits:
- No live ZRAM reset, swap disabling, ZRAM resize, kernel, KMI or partition changes. No new kernel flash is needed.
- v2.10.8 has not been phone-tested.

How to test:
1. Install as a module update through the root manager, then reboot.
2. Open Manager. With ZSTD saved and Apply at boot enabled, the RAM section should show zram0: zstd and "Hook boot ini: zstd load-bpf-programs matching".
3. Or in a root terminal: cat /sys/block/zram0/comp_algorithm; cat /dev/.cogan_smart_zram_init
