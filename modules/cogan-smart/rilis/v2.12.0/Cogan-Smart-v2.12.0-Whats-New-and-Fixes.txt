Batas:

Cara uji:
1. Pasang sebagai pembaruan modul melalui root manager, lalu reboot.
2. Buka tab 📱 Aplikasi: daftar terisi, pilih Semua untuk melihat semua aplikasi.
3. Kirim APK apa saja ke diri sendiri di WhatsApp, lalu coba pasang: harus ditolak. Coba izinkan di Pengaturan: dalam beberapa detik dicabut lagi dan muncul notifikasi.
4. Hapus sampai akar hanya untuk aplikasi yang memang ingin dihapus.

English

New:
- 📱 Apps tab replaces Manager's "Rarely used apps". Each app shows where it came from, dangerous rights, activity (camera, microphone, location, SMS, contacts, phone, clipboard), 7-day internet use and battery.
- 🗑 Remove completely: releases a device admin, removes the app for every user (Dual apps and Second space too), leftover data and identical APK files in storage.
- 🛡️ Block APKs from chat & social apps (on by default): chat, social, email and SMS apps (WhatsApp, Telegram, Signal, Instagram, Facebook, Threads, TikTok, X, Gmail, Outlook, Messages and more) cannot install apps.
- Manager shows the Apps tab summary. The guide gains an Apps section.

Limits:
- Danger marks are guesses from source and rights, not an antivirus. System apps and the root manager cannot be removed. There is no disable button.
- v2.12.0 has not been phone-tested.

How to test:
1. Install as a module update through the root manager, then reboot.
2. Open the 📱 Apps tab: the list fills; choose All to see every app.
3. Send yourself any APK on WhatsApp and try to install it: it must be refused. Allow it in Settings: within seconds it is taken back with a notification.
4. Use Remove completely only on an app you really want gone.
