English

Fixes:
- The 📱 Apps tab no longer fails with "Failed transaction". Android refused command output saved straight into the module folder; it is now read through a pipe.
- The APK block never claims "revoked" when Android cannot read the result back. If rights cannot be read, the block card says "rights not readable".
- The block Enable/Turn off buttons only become active once the block status is read, even when the scan fails.

Limits:
- Not phone-tested yet.

How to test:
1. Install as a module update through the root manager, then reboot.
2. Open the 📱 Apps tab: the list must fill (choose All). If it still fails, send a screenshot of the error.
3. The block card shows on/off, and only one of its buttons can be pressed.
