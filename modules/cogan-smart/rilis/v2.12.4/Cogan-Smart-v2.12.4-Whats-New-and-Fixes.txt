DIPERBAIKI

- Kontrol Daya dan Kontrol Suhu yang dimulai dari WebUI tidak lagi berhenti saat root manager ditutup.
  Penyebabnya, Android mematikan semua proses di cgroup aplikasi root manager saat aplikasi itu
  ditutup. Kini pekerja pindah ke cgroup root saat mulai.
- Keluar dari WebUI cukup satu usapan kembali, sebelumnya berkali-kali.
- Pindai aplikasi di HP gagal dengan "Failed transaction". Penyebabnya, output pm/cmd/dumpsys ke file
  di /data/adb ditolak SELinux. Kini semua bacaan lewat pipa.
- Menambah ke whitelist sebelumnya sekitar 40 detik, kini langsung.
- Pindai aplikasi selesai sebelum batas 120 detik WebUI. Yang belum sempat terbaca disebut "Belum
  terbaca".
- Tombol Aktifkan dan Matikan blokir nonaktif sampai status terbaca. Izin yang tidak terbaca ditandai,
  tidak dianggap sudah dicabut.
- Hanya satu pekerja blokir yang hidup.
- Hook init ZRAM: aturan init yang terpotong diperbaiki (v2.10.6), lalu waktunya dipindah ke
  on load-bpf-programs, sebelum system_perf_init HyperOS menyalakan swap (v2.10.8).
- Penulisan BW DRAM tidak lagi menyasar UFS, GPU atau perangkat lain.
- Terjemahan English yang setengah jadi diperbaiki. Mode English tidak menyisakan teks Indonesia.

ENGLISH

NEW

- 📱 Apps tab (replaces the "Rarely used apps" card). Navigation now has 5 tabs.
  - Each user app shows:
    - install source: app store, APK sent through chat/social apps, or browser/file manager;
    - dangerous rights: reads SMS, accessibility, device admin, reads notifications, draws over other
      apps, may install apps, hidden icon;
    - last camera, microphone, location, SMS, contacts, phone and clipboard access;
    - 7-day internet use and battery since the last full charge.
  - ⛔/⚠️ marks are guesses, not an antivirus. Lists: Needs a look, All, Rarely used (7 days or more).
  - 🗑 Remove completely:
    - releases the device admin, then stops and removes the app for every user (Dual apps and Second
      space too);
    - deletes leftover folders and identical APK copies in storage (e.g. the WhatsApp folder);
    - always asks first; root managers (renamed ones too) and whitelisted apps are protected;
    - there is no disable button.
  - 🛡️ APK block (on by default):
    - 33 chat, social, email and SMS apps cannot install apps, among them WhatsApp, Telegram, Signal,
      Facebook, Instagram, Threads, TikTok, X, LINE, Discord, Gmail, Outlook and Messages;
    - a right turned on again is taken back within seconds, with a notification;
    - the result is read back: a right that could not be taken back is reported as "not revoked"
      instead of being claimed;
    - browsers and file managers can still install apps;
    - turning the block off gives nothing back; allow an app again in Settings yourself.
  - Trust (whitelist), Untrust and the block change at once, without waiting for a scan.
  - 🔍 Search: above the list and visible while scrolling. It matches app names or package names
    across every app.
  - Odd install dates from Android (before 2008, e.g. Netflix "1999-12-31") are labelled "usually a
    preinstalled app".
- Manager:
  - a 📊 Summary card with phone body, battery and processor temperature, controller and recorder
    status, a 1-hour temperature chart, and module and app summaries;
  - Manager only watches: the power mode is set in the Power tab, the module scan in the Modules tab;
  - Save, Apply, Force, Reset, Start and Stop stay in Manager.
- CPU/RAM Manager:
  - Processor: sugov_ext or schedutil, when every CPU policy supports it.
  - ZRAM compression: LZ4 or ZSTD, applied at boot through the root manager's init hook (KernelSU Next
    and BakaSU), before HyperOS starts swap. Live ZRAM is never reset.
  - MediaTek DRAM (mtk-dvfsrc-devfreq) is identified. Unsupported BW choices are hidden.
  - CPU/RAM is written only when the rothko device, the mt6989 platform and Cogan Bridge match.
- Dev mode (a switch in About, off by default) for technical detail: kernel nodes and readback,
  per-policy frequency, ZRAM hooks, DRAM driver, every sensor, raw data and advanced settings.
- 📖 Guide in the module (About and the link under each tab), ID/EN, plus PANDUAN.md / PANDUAN.en.md in
  the repository, including a scam APK FAQ.

FIXED

- Power and Temperature controls started from the WebUI no longer stop when the root manager closes.
  The cause: Android kills every process in the root manager app's cgroup when that app closes.
  Workers now move to the root cgroup when they start.
- Leaving the WebUI takes one back gesture, before it took many.
- The app scan failed on the phone with "Failed transaction". The cause: SELinux refused pm/cmd/dumpsys
  output to files in /data/adb. Every read now goes through a pipe.
- Adding to the whitelist took about 40 seconds, now it is instant.
- The app scan finishes before the WebUI's 120-second limit. What could not be read in time is listed
  as "Not read yet".
- The block's Enable and Turn off buttons stay disabled until the status is read. An unreadable right
  is marked, never counted as revoked.
- Only one block worker runs.
- ZRAM init hook: the cut-off init rule was fixed (v2.10.6), then the hook moved to
  on load-bpf-programs, before HyperOS's system_perf_init starts swap (v2.10.8).
- DRAM BW writes no longer target UFS, the GPU or other devices.
- Half-translated English text is fixed. English mode leaves no Indonesian text.

HOW TO UPDATE

1) Install Cogan-Smart-Kernel-v2.12.4.zip through your root manager as a module update, then reboot.
   The cogan_smart ID, existing settings and history are kept.
2) Close and reopen the Cogan Smart WebUI.
3) If you choose ZRAM compression with Apply at boot: Save, then reboot once.
- Module temperature-based charging pauses stay off by default. HyperCharge and the phone keep managing
  charging. The 95/90 automatic charge cutoff stays available.
